# 本地部署指南

> **created**: 2026-10-07 ｜ **last-change**: 2026-10-08 ｜ **status**: 现行基线

## 1. 简介

本项目为 Chrome 扩展新标签页工作台。本指南记录本地环境准备、生产构建命令、产物隔离要求与扩展加载验证 SOP。

## 2. 索引

[总体设计](../devel/design/00-系统总体设计.md) ｜ [环境治理](../devel/env/README.md)

| 项目 | 当前事实 |
| --- | --- |
| 运行时与构建工具 | Node.js (>=18) + Vite + TypeScript + Tailwind CSS |
| Chrome 最低版本与兼容平台 | Google Chrome MV3 (验证版本 154.0.8037.98) |
| 扩展构建路径 | `local/dist/` (包含 manifest.json、index.html 与 assets/) |
| 后端端口与数据库 | 不适用（纯前端 + Chrome Storage / IndexedDB 本地优先） |
| 部署报告 | `local/deploy_report.md` (完整记录构建产物与测试证据) |

## 3. 规范

构建产物全量隔离收拢至 `local/dist/`，禁止向源码树散落生成未受保护的 bundle。扩展实际加载后，`local/deploy_report.md` 记录真实 Chrome 环境、构建路径与验证事实。后续重载和联调必须依据 `local/deploy_report.md` 真实记录。AI 严禁擅自删除或重置 `local/` 目录。

## 4. 检查、加载与报告

### 4.1 当前检查

在项目根目录执行：

```bash
git status --short
```

输出文档改动与未跟踪治理文件，不生成扩展。工具链未确定时不执行假定的安装或构建命令。

### 4.2 实现后的加载约定

前提是已验证构建命令，且 local/dist/ 包含 manifest.json 与完整资源。届时在 Chrome 扩展管理页开启开发者模式，用“加载已解压的扩展程序”选择实际构建目录；打开新标签页，并按用户选择设置启动时打开新标签页，验证两个入口。商店安装、兼容范围与授权引导在发布准备时补齐。本次未执行加载。

### 4.3 实况报告字段

- 实际时间、Git 分支/提交与未提交改动状态。
- 操作系统、Chrome 版本、扩展版本、扩展 ID 和构建目录。
- 构建命令、退出码、加载错误与日志位置。
- 新标签页、启动页、布局保存、离线与同步的实际结果；未测项标记未验证。
- 无后端时，端口、数据库、PID 与 HTTP 健康端点为不适用。

### 4.4 排错与卸载

加载失败先核对构建目录的 manifest.json 与 Chrome 错误；资源或脚本缺失时核对构建记录。卸载前考虑用户数据备份，具体清理范围另行确定。

### 4.5 独立 HTML 原型预览

两个 HTML 位于 `docs/assets/homepage-study/`，无需安装项目依赖，可直接用浏览器打开。交互 demo 的背景、内容与布局只保存在当前浏览器的原型命名空间。

本次已验证的静态预览命令为：

```bash
python3 -m http.server 4311 --bind 127.0.0.1 --directory docs/assets/homepage-study > local/logs/homepage-preview.log 2>&1
```

从项目根目录运行，前提是 `local/logs/` 已存在且端口空闲。入口为 `http://127.0.0.1:4311/homepage-demo.html` 和 `homepage-style-proposal.html`。仅绑定本机地址，未发布网站或安装扩展。后续重启先查看 `local/deploy_report.md` 的实际端口与进程，避免重复启动；AI 不清理 local/。
