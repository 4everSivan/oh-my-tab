## 4. 设计内容

### 4.1 背景与定位

新标签页和启动入口、网页搜索、常用链接与导航分组。本次以现有需求文档建立清楚的领域边界，不从通用治理模板推断业务源码或运行环境。

### 4.2 目标与非目标

提供网页搜索、常用网站管理、快捷方式分组与排序，并与其他工作台组件共存。

页面独立选择搜索引擎，不改变浏览器全局搜索提供方，不自动修改其他启动模式。是否读取 Chrome 原生书签或历史记录尚未讨论，不能从“常用网站”推断该权限需求。

### 4.4 功能行为与交互

新增链接时填写名称和地址，修改或删除作用于选中的链接，排序和分组修改交由持久化模块保存。网页搜索提交到页面选定的引擎；设置中说明新标签页与浏览器启动设置的关系。

**网页搜索（已确认）**

首页搜索默认 Bing（或 Google），当前仅支持并保留四款精选搜索引擎：必应 (Bing)、谷歌 (Google)、GitHub 与 Bilibili，选择结果本地持久化；不修改 Chrome 全局搜索提供方。输入搜索网页，提交后在新标签页打开选定引擎并保留首页。空白查询不发起请求，查询文本经引擎对应参数正确编码（如 GitHub 的 `q`，Bilibili 的 `keyword`）。它与“筛选常用网站”分开，不将用户的网页查询当成网站过滤条件。

搜索框左侧切换按钮全量采用各家品牌矢量 Logo 图标替代文字，并严格保证图标尺寸一致（18x18px，保证视觉规范一致）。点击图标展开的搜索引擎选择下拉菜单样式与搜索框完全同质化（共享相同的背景透明度、高斯模糊 backdropFilter 与圆角），并在弹出时获得顶层 z-index 保护，且具备全域点击关闭契约：展开后点击页面任意位置（输入框、壁纸、时钟、网站图标等）或按下 Escape 键均可无缝关闭下拉框。搜索框外观与位置规则见 [布局设计 4.6](02-工作台布局与外观.md#46-详细规则与逻辑契约)。

**网站配置与图标（已确认）**

默认网站与自行添加的网站使用相同编辑流程：配置名称和地址，支持添加、移除及排序。只接受 HTTP(S) 网页地址，缺省协议补 HTTPS，无效地址在编辑窗口反馈。图标自动获取；样稿依次尝试站点根目录的 `favicon.ico`、`apple-touch-icon.png`，5 秒内未取得则显示名称首字符。英文首字符大写，中文显示第一个字，emoji 尽量保留完整字符。名称在图标下方显示，所有网站和添加入口使用同一连续圆角轮廓。默认网站名单是当前样稿示例，正式内置名单另行确定。正式扩展可评估 Chrome `_favicon` 能力，权限和实机验证另行处理。

网站日常不显示管理按钮。右键图标弹出桌面式菜单，提供编辑、打开、移除及添加；编辑进入名称与地址窗口。长按图标约 450 ms 后进入拖动，再拖到目标网站位置并松开，保存新顺序。快速点击仍打开网站，拖动结束不触发打开。键盘可用 Shift+F10 打开菜单、Escape 关闭，以及 Alt+左右方向键排序。菜单贴近点击位置并避让窗口边缘；移除后可撤销一次。

编辑窗口打开时填入现有值并聚焦名称；取消保留旧值，保存后更新该网站，不能新增重复记录来替代编辑。菜单支持上下方向键和 Home/End 选择项，关闭或取消后恢复网站焦点。新增网站入口常驻，网站编辑入口集中在右键菜单。

**全局快捷键与键盘导航（已确认）**

为提升高频操作效率，工作台建立统一的全局快捷键分发调度器（`useKeyboardShortcuts`），具备完备的输入态逃逸机制（在 input、textarea 或 contentEditable 元素内打字时普通单键自动休眠避让）：
- **按 `（反引号）**：无论当前焦点位于何处，快速对焦到主页搜索框并自动选中现有文本；当用户处于便签、待办编辑等非搜索输入框时不抢占打字输入；
- **按 Tab / Shift+Tab (C013)**：在搜索框处于聚焦状态时，拦截默认焦点跳转，严格调用 `e.stopPropagation()` 阻止事件向 window 冒泡并在 SearchBar 内部独占消费，基于 `setEngine((prev) => ...)` 函数式原子状态顺次向前/向后循环切换四大搜索引擎（必应 ↔ 谷歌 ↔ GitHub ↔ Bilibili），单次按键仅前进一步，Shift+Tab 逆向倒退一步；空闲态按 Tab 亦由全局拦截器独占顺次切擎，彻底杜绝冒泡双重触发与异步状态滞后；
- **按 Escape**：全局级联退出关闭契约——若快捷键指南/外观抽屉/添加组件弹窗打开，则关闭最顶层弹层；若搜索引擎下拉菜单展开，则收起菜单；若搜索框处于聚焦态，则执行失焦（blur）；
- **按 ?（Shift+/）**：唤起或关闭快捷键全景指南弹窗，向用户直观呈现按键图谱；
- **按 e 或 s**：空闲态下快速打开/关闭外观设置抽屉；
- **按 a**：空闲态下快速打开/关闭添加组件弹窗；
- **按 c**：空闲态下快速切换极简折叠模式 / 展开模式。

**搜索框视觉交互与搜索联想（已确认）**

为提升搜索沉浸感与输入效率，确立以下视觉与联想交互契约：
- **自适应高对比度字色与光标同色契约 (C014)**：搜索框输入文字颜色、光标指示符（`caret-color`）与占位文本根据搜索框表面透明度（`transparency`）与底层壁纸几何采样混合后的有效背景亮度自适应选取高对比度字色（深色有效背景选纯白 `#ffffff`，浅色有效背景选墨黑 `#141c20`），光标指示符与输入文字颜色严格同色一致，占位文本保持同色调半透明协调显示，彻底杜绝硬编码固定色阶在深浅极端背景下辨识不清的缺陷；
- **对焦光标即隐占位契约**：当搜索框获得焦点（光标显示）时，占位提示（“在 xx 中搜索...”）立即隐去；当失去焦点且无输入内容时平滑恢复展示；
- **全引擎搜索联想体系（`SuggestionService`）**：
  - 支持 Bing、Google、Baidu、Bilibili 及 OpenSearch 标准联想协议接口，输入过程通过 180ms 防抖请求；
  - **不记录任何本地搜索历史**：尊重用户隐私，空输入时不展示任何历史下拉浮层，仅在键入关键词后呈现实时匹配联想项；
  - **跨域代理与扩展宿主架构**：在 Chrome 扩展架构中，由注册的 Background Service Worker 结合 `host_permissions` 执行跨域 fetch 请求并通过 `chrome.runtime.sendMessage` 通信，彻底解除浏览器 CORS 阻断；在开发环境由 Vite server proxy 转发支持；
  - 联想悬浮面板采用与搜索框同质化的毛玻璃滤镜与圆角，支持键盘 `ArrowDown` / `ArrowUp` 顺次导航并同步输入框、键盘 `Enter` 直接搜索、`Escape` 或点击任意空白位置收起。

**常用网站导入导出与单排 6 图标分页（已确认·T14）**

为兼顾用户数据安全备份迁移与首页极简清爽的视觉秩序，确立以下规则：
- **网站数据导入导出**：
  - 导出能力：在添加网站弹窗或操作入口提供“导出数据”按钮，将当前所有常用网站数据序列化为规范 JSON 结构（包含版本号、时间戳及 Shortcut 列表）并触发浏览器文件下载；
  - 导入能力：提供“导入数据”入口（支持 JSON 文件上传读取），内置严格的容错与安全防御校验（过滤非法协议如 javascript/data、校验必填字段、自动去重合并或覆盖），导入成功后即时刷新界面并持久化；
- **单排 6 图标展示与多页翻页系统**：
  - 单排 6 槽位限制：首页常用网站区域无论数据多少，**单页至多仅渲染 1 排 6 个图标**，保持横向视觉聚焦与呼吸感，彻底消除随图标增多导致的页面纵向拥挤；
  - 自动分页：当常用网站数量超出 6 个时，按每页 6 个图标自动切分为多页（Page 1, Page 2...）；添加按钮可在最后一页尾部或常驻提供；
  - 滑动翻页交互：在常用网站区域支持触控板/鼠标滚轮上下或左右滚动滑动触发翻页，附带适当的滚动阈值与防抖保护；
  - 键盘方向键翻页 (C018)：当页面处于非文本输入状态（焦点不在任何 input/textarea）时，全局支持按方向键 `ArrowRight` (➡️) 切换至下一页、按方向键 `ArrowLeft` (⬅️) 切换至上一页，契合单排横向排布的空间隐喻；
  - 分页指示器 (T14, C017, C019)：当总页数大于 1 时，在图标下方居中呈现半透明毛玻璃微底托与自适应圆点指示器（Dots）。指示器左侧整合 [←] [→] 左右快捷键键帽按钮与“翻页”提示文字（键帽支持直接点击切页并联动首末页禁用态），中间配有细分隔线，右侧呈现实时页码槽位；圆点高度为 8px (h-2)，当前页展开为 20px (w-5) 胶囊；文字、键帽色彩与投影根据背景自适应继承 textColor 与 shadowProtection，在深色或浅色壁纸下均清晰醒目且具备抗反光阴影，按钮提供充足点击热区，支持悬停全景气泡与点击直达对应页码。

**常用网站图标文件夹（Folder）横向展开系统（已确认·T15）**

为了让用户能够像操作系统桌面或经典导航一样，将多个常用网站收纳进同一个图标文件夹内，确立以下规范：
- **数据契约与平滑向后兼容**：
  - 在 `Shortcut` 模型中扩展 `isFolder?: boolean` 与 `children?: Shortcut[]` 属性；普通网站条目保持 `{ id, name, url }`；文件夹条目为 `{ id, name, isFolder: true, children: Shortcut[] }`；
  - 文件夹本身作为单排 6 图标中的一个标准槽位存在，彻底继承原有的单排 6 槽位与左右按键/滚轮翻页调度，零割裂感。
- **文件夹图标视觉与 2x2 缩略预览**：
  - 文件夹采用与普通网站同尺寸的连续平滑连续圆角图标外壳（w-12 h-12 rounded-2xl）；
  - 容器内部自动呈现其收纳的前 4 个站点的 2x2 极简微缩网格（优先 Favicon、缺失兜底首字符），直观感知内部内容；空文件夹展示文件夹微矢量图；下方居中展示文件夹名称。
- **点击横向展开交互契约**：
  - 点击文件夹图标触发**横向展开（Horizontal Expansion）**：在单排图标下方平滑展开具有高级毛玻璃质感的横向抽屉托盘；
  - 展开托盘内横向紧凑排布该文件夹下的所有子网站图标，支持直接点击任意网站跳转；
  - 托盘支持横向平滑滚动浏览，内含快捷添加网站按钮，支持点击关闭按钮或点击页面空白顺畅收起；
  - **自适应背景取色契约 (C020)**：毛玻璃横向抽屉托盘、主排文件夹图标与子项图标容器全面接入壁纸与背景自适应取色管线。深色背景（如深色壁纸、暗夜材质）选用深色黑曜石毛玻璃（`rgba(18, 18, 22, 0.72)`）与微光高透边框；浅色背景选用高透晶莹毛玻璃（`rgba(255, 255, 255, 0.76)`）；字色、阴影与子项图标容器全量自适应匹配，彻底杜绝深色壁纸下呈现割裂白底。
- **收纳与整理交互**：
  - 拖拽归纳：支持长按拖拽图标直接移入文件夹图标中；
  - 右键菜单归纳：普通图标右键支持“移入文件夹”；文件夹右键支持“重命名”、“解散文件夹”（子站点解包回顶层）与“移除文件夹”；
  - 添加弹窗：支持自由选择添加普通“网站”或新建“文件夹”。
- **iTab 备份原生 1:1 结构互通**：
  - 解析导入 iTab 备份数据（如 `.itabdata`）时，识别 `type: "folder"` 节点，原汁原味将其子站点转换为 `oh-my-tab` 的图标文件夹，不再粗暴打散，完美复原用户的收藏结构。

### 4.5 建议架构与 Topic

主题锚点为 `EntryNavigation`。

建议分为入口适配、导航领域数据与搜索适配三部分。入口只负责加载工作台；导航操作通过持久化模块保存；布局模块决定分组的展示位置。入口与导航不直接处理同步协议或外部数据源。

### 4.6 详细规则与逻辑契约

Shortcut 包含稳定标识、显示名称、HTTP(S) 地址和顺序；支持 `isFolder: true` 与 `children: Shortcut[]` 嵌套文件夹契约，文件夹在顶层作为单槽位参与单排 6 图标自动切片分页。修改名称/地址保留标识和相对顺序，修改地址后重新取得图标；排序仅改变网站顺序。图标结果不承担网站身份，缺图不影响链接打开。

| 原型约束 | 当前值或规则 | 正式实现边界 |
| --- | --- | --- |
| 名称 | 去除首尾空白后 1–30 个字符 | 保留非空校验，正式长度限额需验证 |
| 地址 | 有效 HTTP(S)，不允许 URL 中嵌入用户名/密码；上限 2048 字符 | 不支持可执行协议或本地文件链接 |
| 图标来源 | 仅配置网站的 origin，顺序 favicon → touch icon；5 秒回退 | 正式 Chrome 图标 API、缓存和权限待定 |
| 长按排序 | 阈值 450 ms，拖动成功后保存，禁止带出点击导航 | 实际鼠标/触控板体验待验证 |
| 网页搜索 | 选定引擎（必应/谷歌/GitHub/Bilibili）、查询参数与 URL 编码；回车在当前页面（window.location.href）直接跳转；空白不提交 | 正式环境使用当前标签页直接导航 |

正式存储键、标识生成及浏览器 API 契约尚未冻结；页面初始焦点与 Chrome 地址栏行为需要实机验证。

### 4.7 扩展、异常与实施前决策

建议对无效输入提供明确反馈，保存失败时不显示成功。核心链接数据从本地加载，外部图标或网络资源异常不阻塞导航。浏览器选择恢复上次页面或固定启动网页时，遵循该设置；无痕窗口不覆盖新标签页。

样稿采用新标签页打开网页、网站自身图标及 HTTP(S) 限制，并提供键盘操作。正式扩展仍需确定分组交互、Chrome 图标 API 权限与实机兼容性。原生书签导入属于另行讨论的能力。

### 4.8 后续验证与参考资料

2026-10-07 的 HTML 原型已验证网站编辑、添加、首字符回退、移除撤销、引擎切换与刷新保存，以及右键菜单和编辑窗口，记录于 `local/homepage-minimal-browser-check.json`。排序规则和长按阈值有 Node 回归；键盘排序不能代替指针长按手感验证。2026-10-08 用户确认上述设计，不代表实际 Chrome 导航结果已验收。

正式实现需核验：默认 Google、引擎选择刷新保留；合法 URL 编辑保持同一记录，无效输入不保存；缺图仍能辨认并打开网站；右键菜单避让边缘且可键盘操作；短按打开、长按拖动不误打开、顺序刷新保留；两个入口一致性及三种启动模式。分组与实际搜索新标签页仍待实现和验证。
