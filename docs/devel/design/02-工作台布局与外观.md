## 4. 设计内容

### 4.1 背景与定位

组件自由布局、主题、壁纸、时钟与样式恢复。本次以现有需求文档建立清楚的领域边界，不从通用治理模板推断业务源码或运行环境。

### 4.2 目标与非目标

支持组件拖动、缩放、排序，导航分组排列，壁纸、主题、时钟与自定义 CSS，保存个性化页面。

本轮确认首页交互与外观，不选定正式前端框架、拖拽库或栅格算法，不以任意脚本执行替代 CSS 定制。窄窗口适配属于 Chrome 页面可用性要求，不表示增加移动端浏览器产品。

### 4.3 需求清单

| 编号 | 能力 | 需求或规划规则 |
| --- | --- | --- |
| LAY-01 | 布局编辑 | 用户能调整组件位置、大小与顺序，并保存布局。 |
| LAY-02 | 视觉配置 | 用户能调整主题、壁纸、时钟和页面外观。 |
| LAY-03 | 不同窗口 | 窗口尺寸变化时保留可用的内容展示与操作入口。 |
| LAY-04 | 深度样式 | 提供 CSS 编辑，并设计布局或样式异常后的恢复能力。 |
| LAY-05 | 自定义背景 | 支持默认材质、自选纯色、本地图片；图片可调整画面位置、遮罩与模糊。 |
| LAY-06 | 默认首页 | 从上到下为时间与日期、网页搜索、常用网站；效率组件由用户自行添加。 |
| LAY-07 | 时间收起 | 点击时间收起网站、组件和辅助界面，再次点击恢复内容与布局。 |
| LAY-08 | 时间外观 | 默认无框、无描边、无阴影；支持字体、字号、字重、位置、日期/秒数开关及可选深色投影。 |
| LAY-09 | 搜索框外观 | 支持位置、间距、宽度、背景透明度与背景模糊；文字保持不透明且不模糊。 |
| LAY-10 | 设置与恢复 | 外观设置即时预览、自动本地保存；时间和搜索框分别恢复默认，不删除其他配置或内容。 |

非功能方向沿用 README：快速打开、本地优先、权限范围清楚、独立组件失败可降级。量化性能和资源预算仍需首版方案确定，不填入未经验证的指标。

### 4.4 功能行为与交互

**默认布局与收起行为（已确认）**

首页从上到下显示时间与日期、网页搜索栏、常用网站。时间和搜索默认居中，组件初始为空，用户通过“添加组件”选择后才出现对应卡片。组件内容与展示布局分开保存；移除只移出布局。网站图标采用统一连续圆角方形，参考 Apple 图标轮廓，样稿使用共享 SVG 曲线近似，不绑定某个 Apple 系统版本的精确遮罩。

时间与日期没有矩形背景、黑色半透明框或白色描边。点击时间进入收起状态，隐藏网站、已添加组件、页眉操作、页脚和样稿评审工具，保留时间、按设置显示的日期及网页搜索。再次点击恢复原内容与顺序，不重置配置。该状态仅影响当前页面，刷新回到展开状态。网站右键管理与长按排序见 [导航设计 4.4](01-页面入口与导航.md#44-功能行为与交互)。

**设置面板与即时预览（已确认）**

右上角外观设置打开侧边面板，分为“时间”“搜索框”“背景与风格”。桌面窗口保留首页预览空间，窄窗口使用可滚动的底部面板。调节即时生效并自动本地保存，“完成”或关闭只收起面板，不撤销已经生效的设置。Escape 关闭后恢复设置入口焦点；分组支持方向键切换。

时间可调字体风格、字号、字重、水平位置、顶部留白，独立开关日期与秒数；默认无阴影，可选柔和深色投影。搜索框可调水平位置、上方间距、宽度、背景透明度与背景模糊。透明度 0% 为实色背景、100% 为透明背景，不淡化输入文字和按钮；模糊只作用于框后的画面。两组分别恢复默认，不修改背景、网站、搜索引擎、组件布局或内容。此操作与样稿评审条中的“恢复样稿”不同，后者会重置示例内容。

**背景与可读性（已确认）**

背景独立于组件主题，支持默认材质、自选纯色和导入本地图片；图片可调整居中/靠上/靠下、遮罩强度和背景模糊。图片保留在本地。纸感书桌、雾蓝工作台和墨黑仪表台继续作为材质候选；纸感是当前样稿初始值，正式产品默认材质尚未单独选定。样稿图片限 PNG/JPEG/WebP、2 MB，正式容量与资源存储方案另行设计。

品牌、日期、时钟、网站名称与页脚根据各自所在区域的背景选择深字或浅字，计入裁切、位置、遮罩与模糊。
2026-10-09 现行基线（T09）：全站引入离线 Canvas 几何像素采样引擎（`useWallpaperContrast` Hook）。在用户加载图片壁纸（`background.type === 'image'`）或自选纯色时，将壁纸以最大 384px 等比投影至离线 Canvas 并合成 `blur`、`shade` 与 `coverRect`；根据时钟、搜索栏、常用网站的实际屏幕边界（`getBoundingClientRect`）采样像素矩阵，按 WCAG 2.2 sRGB 相对亮度公式计算区域对比度：
- 当背景区域为深色时，自动选取纯白墨水（`#ffffff`，对比度达 16.8:1）；
- 当背景区域为浅色时，自动选取墨黑墨水（`#141c20`）；
- 当采样区域处于复杂高频纹理或明暗交界处（对比度 `< 4.5:1`）时，自动叠加自适应文字光晕保护（深色区域叠加柔和深阴影 `0 2px 12px rgba(0,0,0,0.4)`，浅色区域叠加柔和浅晕），确保任何壁纸下 100% 清晰可读；
- 图片加载中或采样失败时，优雅回退至安全底色，不阻塞界面交互。

**组件栅格形态（2026-10-08 定调方向）**

组件区采用 12 列栅格、按跨度（span）流式排布；“自由布局”指栅格内的跨度、顺序与尺寸调整，不采用绝对定位自由画布。若未来引入自由画布，作为附加布局模式另行设计，不改动组件实例数据模型。跨度可选值与窄窗口降档随组件契约的 `supportedSpans` 冻结，见 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约)。

### 4.5 建议架构与 Topic

主题锚点为 `WorkspaceAppearance`。

建议拆为布局模型、交互控制、主题配置、资源引用和 CSS 适配。组件仅声明展示需求，布局层负责摆放；数据层负责保存配置和资源。CSS 与外部资源不应承担导航或待办业务逻辑。

### 4.6 详细规则与逻辑契约

**时间配置的初始值与可调范围**

以下为本轮已确认首页方案的初始参数；字段名用于逻辑建模，不代表正式扩展存储 schema 已冻结。

| 设置 / 字段 | 默认值 | 可选值或范围 | UI 步长 / 语义 |
| --- | --- | --- | --- |
| 字体 `clock.font` | `modern` | `modern` / `mono` / `serif` | 现代系统字体 / 等宽 / 衬线，使用本地字体及回退 |
| 字号 `clock.size` | 96 px | 48–144 px | 4 px；窄窗口可收敛实际字号 |
| 字重 `clock.weight` | 400 | 200–800 | 100；实际显示由可用字体决定 |
| 水平位置 `clock.align` | `center` | `left` / `center` / `right` | 相对首页内容区 |
| 顶部留白 `clock.top` | 56 px | 0–240 px | 2 px；内容流中时间组上方留白，不是屏幕绝对坐标 |
| 阴影 `clock.shadow` | `none` | `none` / `soft` | 关闭 / 柔和深色投影，均无描边 |
| 日期 `clock.showDate` | 显示 | 显示 / 隐藏 | 不改变秒数选项 |
| 秒数 `clock.showSeconds` | 隐藏 | 显示 / 隐藏 | 时:分或时:分:秒 |

**搜索框配置的初始值与可调范围**

| 设置 / 字段 | 默认值 | 可选值或范围 | UI 步长 / 语义 |
| --- | --- | --- | --- |
| 水平位置 `search.align` | `center` | `left` / `center` / `right` | 独立于时间对齐 |
| 上方间距 `search.gap` | 30 px | 0–120 px | 2 px；时间组与搜索框之间 |
| 宽度 `search.width` | 600 px | 320–760 px | 20 px；实际宽度不超过内容区 |
| 背景透明度 `search.transparency` | 15% | 0–100% | 5%；默认背景不透明度为 85% |
| 背景模糊 `search.blur` | 12 px | 0–24 px | 1 px；与整页背景模糊独立 |

时间与搜索设置分别保存，恢复某一组只恢复该组表格默认值。读入配置时补齐缺失字段、限制数值范围并校验枚举，不直接将任意字符串写入样式；具体兼容规则见 [数据设计 4.6](04-数据保存与同步.md#46-详细规则与逻辑契约)。设置面板缩小预览区域时，不覆盖已保存的字号和宽度。时间收起状态会在当前顶部留白之外增加适配窗口高度的间距，保留已选择的字体、字重和搜索材质。

组件 LayoutItem 包含实例标识、跨度、顺序与尺寸约束，Appearance 分开记录背景、主题、时间和搜索选项。组件区栅格形态已定调为 12 列 span 流式布局（不做绝对定位自由画布）；span 可选值、窄窗口降档与重排算法、资源引用、CSS 作用范围及存储 API 尚未冻结，跨度能力由组件契约声明，见 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约)。

### 4.7 扩展、异常与实施前决策

大壁纸资源留在本地，Chrome 同步只考虑适合配额的配置和引用。建议对重叠、超出窗口、图片失效和保存失败提供可恢复反馈；CSS 应能被停用并恢复默认样式，恢复入口的隔离方式在实现前明确。

首页顺序、时间收起、侧边设置、独立恢复与网站操作已确认，组件栅格形态已定调，不再列为未决项。实施前仍需确定正式默认材质、拖拽交互库与栅格重排/降档算法、自定义 CSS 的注入作用域（默认限定在页面工作区内，防 `url()` 数据外传与全页覆盖）及停用恢复的隔离入口、正式壁纸容量、保存失败处理和扩展运行兼容性。样稿以 850 px 分界切换侧栏/底部面板，该数值作为实现参考，需按正式页面验证；并未承诺配置历史或多步撤销。

### 4.8 后续验证与参考资料

首页交互及设置细节已于 2026-10-08 获用户确认。原型已在 Codex 内置浏览器检查风格切换、组件排序与宽度调整、内容保存及背景导入；正式 Chrome 扩展加载、图片容量边界、同步、CSS 定制及发布验收仍待实现，网站指针长按排序手感仍需人工验证。

后续实现按以下可观察标准核验：默认顺序与空组件布局正确；时间无框、无白边；点击时间收起/恢复不丢内容；每项设置即时生效且刷新保留；恢复时间不改变搜索及其他内容，恢复搜索不改变时间及其他内容；搜索背景透明/模糊不影响输入文字；窄窗口的大字号及搜索宽度不越界；背景或文字位置改变后重新选色。

原背景修正通过 12 项 Node 回归测试和三种主题的背景导入、调节、裁切及缩放检查；旧观察保存在 `local/homepage-contrast-browser-check.json`。随后检查时间收起及恢复、网站右键编辑和组件添加后保存，观察保存在 `local/homepage-minimal-browser-check.json`。当前共有 35 项配置与背景回归，新增外观参数边界、旧配置兼容、保存加载与搜索框表面合成；设置预览、刷新保存及窄窗口观察保存在 `local/homepage-appearance-browser-check.json`。普通背景文字保护以 4.8:1 为采样目标留量；时间与日期默认无框、无阴影、逐字符换色，可选柔和深色投影，不声称混合图片的每个像素均达到该比值，也不构成无障碍审计。测试使用独立 localhost 来源，保留 127.0.0.1 来源的原背景与内容。
