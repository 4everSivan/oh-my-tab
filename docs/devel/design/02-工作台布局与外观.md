## 4. 设计内容

### 4.1 背景与定位

组件自由布局、主题、壁纸、时钟与样式恢复。本次以现有需求文档建立清楚的领域边界，不从通用治理模板推断业务源码或运行环境。

### 4.2 目标与非目标

支持组件拖动、缩放、排序，导航分组排列，壁纸、主题、时钟与自定义 CSS，保存个性化页面。

本轮确认首页交互与外观，不选定正式前端框架、拖拽库或栅格算法，不以任意脚本执行替代 CSS 定制。窄窗口适配属于 Chrome 页面可用性要求，不表示增加移动端浏览器产品。

### 4.4 功能行为与交互

**首页极简布局与小钟（2026-11-10 现行基线·T20）**

2026-11-10 用户确认首页改版：从大时钟 + 搜索 + 单排网站图标的旧布局，收敛为「小钟 + 搜索」的极简首页，常用网站全部迁入独立启动台页面（见 [导航设计 4.4](01-页面入口与导航.md#44-功能行为与交互)）。现行规则：

- 默认首页自上而下只保留顶栏、搜索区与页脚；效率组件仍由用户通过顶栏「+」自行添加，添加后按 12 列栅格展示，默认不出现任何组件卡片。
- 小钟位于搜索框左上方并与搜索框左边缘对齐，一行显示 `时:分` 与「月日 周几」；不使用钟表图标，不提供字体、字号、字重、水平位置、顶部留白、日期/秒数开关、时区等外观设置。时间跟随本地系统时区，分钟级更新即可。
- 小钟固定参与搜索区自适应取色：根据其所在区域背景选择深色墨黑或纯白字色，并在复杂背景上启用文字光晕保护；小钟不承担点击收起/展开等交互。
- 大时钟、点击时间进入极简模式、`C` 键折叠与 `workspace-container` 折叠过渡一并移除；刷新与重开页面始终为展开的极简首页。
- 默认无组件时，小钟与搜索框作为整体在可视区垂直居中：以搜索框自身中线对齐视口中线，小钟位于其上方约 30px；添加任意效率组件后回到顶部布局，搜索区在上、组件栅格在下，页面按需滚动。
- 搜索框视觉配置（对齐、宽度、圆角、背景透明度、背景模糊）保留并即时保存；搜索框上方间距改由布局固定，不再作为用户设置项。

**设置面板与即时预览（已确认·T20）**

右上角外观设置打开悬浮侧边面板，现行只保留「搜索」「壁纸」两个分段；时钟与网站快捷键分段随对应功能移除。搜索、壁纸调节即时生效并自动本地保存，“完成”或关闭只收起面板，不撤销已经生效的设置。Escape 关闭后恢复设置入口焦点；分段支持方向键切换。

搜索框可调水平位置、宽度、圆角、背景透明度与背景模糊；透明度 0% 为实色背景、100% 为透明背景，不淡化输入文字和按钮；模糊只作用于框后的画面。「壁纸」分段末尾提供「启动台背景模糊」滑块（C040）：该值作为背景配置的 `launchpadBlur` 字段保存，对材质、纯色与图片三种背景均生效；旧版数据没有该字段时按默认 30px，越界值钳制到 0~40。外观设置仍为「搜索 / 壁纸」两段，不为此新增分段。搜索与背景分别恢复默认，不修改网站、搜索引擎或组件布局与内容。此操作与样稿评审条中的“恢复样稿”不同，后者会重置示例内容。

**背景与可读性（已确认）**

背景独立于组件主题，支持默认材质、自选纯色和导入本地图片；图片可调整居中/靠上/靠下、遮罩强度和背景模糊。图片保留在本地。纸感书桌、雾蓝工作台和墨黑仪表台继续作为材质候选；纸感是当前样稿初始值，正式产品默认材质尚未单独选定。样稿图片限 PNG/JPEG/WebP、2 MB，正式容量与资源存储方案另行设计。

小钟、搜索框、页脚与顶栏图标的字色根据各自所在区域的背景选择深字或浅字，计入裁切、位置、遮罩与模糊。常用网站名称随启动台独立页面处理，不再参与首页取色。
2026-10-09 现行基线（T09）：全站引入离线 Canvas 几何像素采样引擎（`useWallpaperContrast` Hook）。在用户加载图片壁纸（`background.type === 'image'`）或自选纯色时，将壁纸以最大 384px 等比投影至离线 Canvas 并合成 `blur`、`shade` 与 `coverRect`；根据小钟与搜索栏的实际屏幕边界（`getBoundingClientRect`）采样像素矩阵，按 WCAG 2.2 sRGB 相对亮度公式计算区域对比度：
- 当背景区域为深色时，自动选取纯白墨水（`#ffffff`，对比度达 16.8:1）；
- 当背景区域为浅色时，自动选取墨黑墨水（`#141c20`）；
- 当采样区域处于复杂高频纹理或明暗交界处（对比度 `< 4.5:1`）时，自动叠加自适应文字光晕保护（深色区域叠加柔和深阴影 `0 2px 12px rgba(0,0,0,0.4)`，浅色区域叠加柔和浅晕），确保任何壁纸下 100% 清晰可读；
- 图片加载中或采样失败时，优雅回退至安全底色，不阻塞界面交互。

**组件栅格形态（2026-10-08 定调方向）**

组件区采用 12 列栅格、按跨度（span）流式排布；“自由布局”指栅格内的跨度、顺序与尺寸调整，不采用绝对定位自由画布。若未来引入自由画布，作为附加布局模式另行设计，不改动组件实例数据模型。跨度可选值与窄窗口降档随组件契约的 `supportedSpans` 冻结，见 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约)。

**顶栏双胶囊解耦与独立订阅消息侧边栏（已确认·T17）**

为使工作台在满足沉浸式视觉定制的同时，提供高效的新闻与动态订阅能力，确立以下顶栏与双抽屉架构规范：
- **顶栏右上角双圆形胶囊按钮**：
  - `[ 🔔 订阅消息栏 ]`：左侧为独立的磨砂玻璃圆形胶囊按钮（`w-9 h-9 rounded-full`），配备带呼吸动效的红色未读角标（`hub-badge`）；
  - `[ ⚙️ 外观与桌面设置 ]`：右侧为纯粹的系统设置圆形胶囊按钮，专用于桌面壁纸、时钟、搜索栏样式与小组件布局配置；
  - 两个按钮采用统一的高级磨砂视觉语言（`backdrop-filter: blur(12px)`），状态互斥联动，点击其中一个时自动收起另一个，彻底解耦。
- **独立订阅消息侧边栏（Feed Sidebar Drawer）**：
  - 抽屉固定停靠在视口右侧（`width: 420px`，移动端/窄窗口自适应满屏），采用圆角悬浮磨砂卡片质感（`rounded-2xl shadow-2xl`）与平滑右滑入场动效（`hub-slide-r`）；
  - 背景辅以轻量高斯模糊透明遮罩（`feed-backdrop`），支持点击遮罩或右上角关闭按钮快速收起；
  - 抽屉聚焦于动态订阅信息流（GitHub 趋势、科技前沿、技术博客、待办提醒等），支持按分类标签（全部/GitHub/科技/博客/待办）即时筛选过滤；
  - 提供未读条数徽标与“全部已读”一键清标能力，点击单条消息或一键已读后即时更新右上角 🔔 未读红点角标。
- **纯粹外观设置抽屉（Appearance Drawer）**：
  - 严格聚焦于桌面外观配置（搜索框、背景与壁纸），彻底移出所有订阅消息流与杂质内容；2026-11-10 T20 起不再包含时钟与网站快捷键分段，符合现代操作系统“控制中心/系统设置”与“通知中心”的职责隔离准则。

### 4.5 建议架构与 Topic

主题锚点为 `WorkspaceAppearance`。

建议拆为布局模型、交互控制、主题配置、资源引用和 CSS 适配。组件仅声明展示需求，布局层负责摆放；数据层负责保存配置和资源。CSS 与外部资源不应承担导航或待办业务逻辑。

### 4.6 详细规则与逻辑契约

**小钟固定规格（2026-11-10 现行基线·T20）**

大时钟的字体/字号/字重/对齐/顶部留白/阴影/日期/秒数/时区配置全部废弃；`ClockAppearance` 不再参与首页渲染与外观设置。小钟使用固定规格：

| 项目 | 固定值 | 说明 |
| --- | --- | --- |
| 位置 | 搜索框左上方、与搜索框左边缘对齐 | 位于搜索框上方 10px，随搜索框对齐方式移动 |
| 时间 | `HH:mm`（24 小时制） | 13px / 600 字重 / tabular-nums，跟随本地系统时区 |
| 日期 | `M月D日 周X` | 12px / 常规字重，与时间同一行，间隔 7px |
| 图标 | 无 | 不显示钟表图标 |
| 配置 | 无 | 不提供任何时钟外观、时区或显示项设置 |
| 取色 | 继承搜索区背景采样 | 深色背景纯白、浅色背景墨黑，复杂背景启用光晕保护 |

**搜索框配置的初始值与可调范围**

| 设置 / 字段 | 默认值 | 可选值或范围 | UI 步长 / 语义 |
| --- | --- | --- | --- |
| 水平位置 `search.align` | `center` | `left` / `center` / `right` | 独立于页面其他元素 |
| 宽度 `search.width` | 600 px | 320–760 px | 20 px；实际宽度不超过内容区 |
| 背景透明度 `search.transparency` | 15% | 0–100% | 5%；默认背景不透明度为 85% |
| 背景模糊 `search.blur` | 12 px | 0–24 px | 1 px；与整页背景模糊独立 |
| 圆角 `search.radius` | 24 px | 0–28 px | 2 px；0 px 为直角矩形，24 px 为胶囊圆角，28 px 为全圆角 |

搜索与背景设置分别保存，恢复某一组只恢复该组表格默认值。读入配置时补齐缺失字段、限制数值范围并校验枚举，不直接将任意字符串写入样式；具体兼容规则见 [数据设计 4.6](04-数据保存与同步.md#46-详细规则与逻辑契约)。设置面板缩小预览区域时，不覆盖已保存的宽度。`search.gap` 保留为历史字段但不再作为用户可调项，布局按固定间距处理。

组件 LayoutItem 包含实例标识、跨度、顺序与尺寸约束，Appearance 分开记录背景、搜索选项与组件布局。组件区栅格形态已定调为 12 列 span 流式布局（不做绝对定位自由画布）；span 可选值、窄窗口降档与重排算法、资源引用、CSS 作用范围及存储 API 尚未冻结，跨度能力由组件契约声明，见 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约)。

**闲置聚焦淡化系统移除（2026-11-10 现行基线·T20）**

T19 引入的闲置聚焦淡化系统（`useIdleDetection`、`settings.idle`、外观抽屉闲置配置、`t-idle-*` 令牌与 `MOT-14`）自 2026-11-10 起整体移除。页面不再在无操作后淡出、不保留“只显示搜索框”的闲置态，也不存在唤醒入口或闲置态快捷键挂起；搜索框、顶栏、页脚与组件区始终按正常交互态呈现。相关 CSS 令牌、组件属性（`suspended`、`data-idle`）与设置项一并删除，设计 07 的 MOT-14 同步废止。

### 4.7 扩展、异常与实施前决策

大壁纸资源留在本地，Chrome 同步只考虑适合配额的配置和引用。建议对重叠、超出窗口、图片失效和保存失败提供可恢复反馈；CSS 应能被停用并恢复默认样式，恢复入口的隔离方式在实现前明确。

首页顺序、小钟位置、搜索区外观、启动台入口与外观设置范围已确认，组件栅格形态已定调，不再列为未决项。实施前仍需确定正式默认材质、拖拽交互库与栅格重排/降档算法、自定义 CSS 的注入作用域（默认限定在页面工作区内，防 `url()` 数据外传与全页覆盖）及停用恢复的隔离入口、正式壁纸容量、保存失败处理和扩展运行兼容性。样稿以 850 px 分界切换侧栏/底部面板，该数值作为实现参考，需按正式页面验证；并未承诺配置历史或多步撤销。启动台的页面结构、网格与文件夹规则见导航设计 T20 小节。

### 4.8 后续验证与参考资料

首页交互及设置细节已于 2026-10-08 获用户确认。原型已在 Codex 内置浏览器检查风格切换、组件排序与宽度调整、内容保存及背景导入；正式 Chrome 扩展加载、图片容量边界、同步、CSS 定制及发布验收仍待实现，网站指针长按排序手感仍需人工验证。

后续实现按以下可观察标准核验：默认首页只呈现小钟与搜索、组件默认不出现；小钟位于搜索框左上方并与搜索框左边缘对齐，无钟表图标、无点击收起；默认无组件时搜索框自身在视口垂直居中，添加组件后搜索区回到顶部；搜索与背景每项设置即时生效且刷新保留；恢复搜索不改变背景及其他内容；搜索背景透明/模糊不影响输入文字；窄窗口的大字号及搜索宽度不越界；背景或搜索位置改变后重新选色；闲置模式与时钟/快捷键设置不残留。2026-11-10 启动台弹出、关闭与入场/退场淡入淡出在 `tests` 与实机截图中同时核对。

原背景修正通过 12 项 Node 回归测试和三种主题的背景导入、调节、裁切及缩放检查；旧观察保存在 `local/homepage-contrast-browser-check.json`。随后检查时间收起及恢复、网站右键编辑和组件添加后保存，观察保存在 `local/homepage-minimal-browser-check.json`。当前共有 35 项配置与背景回归，新增外观参数边界、旧配置兼容、保存加载与搜索框表面合成；设置预览、刷新保存及窄窗口观察保存在 `local/homepage-appearance-browser-check.json`。普通背景文字保护以 4.8:1 为采样目标留量；时间与日期默认无框、无阴影、逐字符换色，可选柔和深色投影，不声称混合图片的每个像素均达到该比值，也不构成无障碍审计。测试使用独立 localhost 来源，保留 127.0.0.1 来源的原背景与内容。
