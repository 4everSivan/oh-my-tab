## 4. 设计内容

### 4.1 背景与定位

待办、便签、日历等内置组件的行为与独立状态。本次以现有需求文档建立清楚的领域边界，不从通用治理模板推断业务源码或运行环境。

### 4.2 目标与非目标

让用户按需添加、移除和配置组件，独立展示状态，并在本地优先的工作台中组织个人内容。

本次不承诺所有组件都进入首版；未决定提醒通知、重复任务、富文本或特定第三方日历集成。独立账号和团队协作不属于已确认目标。

### 4.3 需求清单

| 编号 | 能力 | 需求或规划规则 |
| --- | --- | --- |
| WID-01 | 组件组合 | 待办、便签、日历等组件可与导航同时使用。 |
| WID-02 | 组件管理 | 默认不放置组件，用户自行添加；移除只隐藏，重新添加保留内容。 |
| WID-03 | 独立状态 | 一个外部数据源失败时其他组件继续使用。 |
| WID-04 | 个人内容 | 本地保存为基础，是否同步待办和便签需进一步确定。 |

非功能方向沿用 README：快速打开、本地优先、权限范围清楚、独立组件失败可降级。量化性能和资源预算仍需首版方案确定，不填入未经验证的指标。

### 4.4 功能行为与交互

**添加与移除（已确认）**

新首页默认只显示时间、搜索和网站，组件列表为空。右上角“添加组件”打开选择窗口，用户选择后卡片才加入首页；已经添加的类型禁用重复添加。移除卡片只改变展示列表，不删除待办或便签内容；再次添加恢复内容。通过“编辑首页”调整已添加卡片的位置和宽度，完成后退出编辑。点击时间收起时，组件与网站一起隐藏，展开后恢复。“禁用重复添加”与“最多一个”是首版交互政策而非数据结构约束：实例数据模型自始支持多实例，放开与否只调整添加入口的置灰规则，无需迁移数据，见 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约)。

**当前原型候选**

| 组件 | 样稿操作 | 尚未定义的正式范围 |
| --- | --- | --- |
| 撕页日历 | 显示日期、点击翻页、回到今天 | 外部日历、时区和事件数据 |
| 专注计时 | 15/25/45 分钟选择、开始/暂停 | 通知、后台及跨刷新计时 |
| 今日待办 | 添加、勾选完成、展示进度 | 提醒、重复任务、内容删除/导出 |
| 随手便签 | 编辑文字、显示本地保存状态 | 富文本、内容删除/导出 |

以上用于展示按需组合，不把四类候选自动冻结为正式首版完整清单。样稿待办 30 条、便签 600 字符是演示容量限制，正式容量另行确定。

**首版 (v0.1.0) 内置效率组件决策（2026-10-08）**

2026-10-08 用户决策首版核心内置组件范围：
1. **今日待办 (Todo)**：纳入首版，支持待办项新增、勾选完成、删除与命名空间隔离持久化；
2. **随手便签 (Notes)**：纳入首版，支持快速文本记录、多行输入与自动本地保存；
3. **专注计时 (Focus Timer)**：纳入首版，支持预设倒计时/番茄钟、跨刷新状态恢复与桌面系统通知；
4. **撕页日历 (Calendar)**：首版暂缓实施，延后至下一阶段规划。

### 4.5 建议架构与 Topic

主题锚点为 `ProductivityWidgets`。

内置组件通过共同的组件契约与布局层交互（契约单一来源见 [06-组件契约与注册.md](06-组件契约与注册.md)）；业务内容通过持久化层按实例命名空间保存；联网组件通过外部数据源模块请求数据。组件不直接控制整体页面布局或向同步存储发送任意内容。

### 4.6 详细规则与逻辑契约

组件定义（类型、可配置项、显示要求）、组件实例（实例标识、类型、配置）与业务内容（待办记录、便签正文、日历数据）的三分结构及字段建议已收拢至 [组件契约设计 4.6](06-组件契约与注册.md#46-详细规则与逻辑契约) 作为单一来源；本模块引用该契约，具体字段、生命周期与更新接口仍无冻结的数据 schema。

展示列表与业务内容必须分别管理：添加不复制已有内容，移除不清空内容，外观设置恢复不改变任何组件数据。当前首页方案每种内置组件最多展示一个，属于首版交互政策；多实例的数据模型已在组件契约中预留，放开策略与内容共享方式仍待设计。专注剩余秒数、日历翻页状态等临时状态不视为已确认的持久化契约。

### 4.7 扩展、异常与实施前决策

纯本地组件离线可用；外部日历和其他联网能力采用独立加载、错误或缓存状态。缺少权限与认证失败在该组件反馈，不阻塞导航。凭据不放入普通配置同步，私密内容默认保留本地。

需明确首版组件与各自完整范围、主动删除内容的行为、深度扩展多实例策略、正式日历展示类型与时区、个人数据导出和可选同步范围；另需补充组件添加/移除/排序的键盘操作路径与组件名称/设置文案的国际化方案。按需添加及移除保留内容已确定，具体外部日历提供方尚未选定。
